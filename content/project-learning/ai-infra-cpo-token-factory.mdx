## 一句话结论

AI 正在从“模型竞赛”进入“Token 工厂竞赛”。

未来 AI 的核心生产资料不只是模型参数，而是稳定、低成本、高效率地产生 Token 的能力。Token 背后对应的是算力、存力和高速互联。谁能把 GPU/TPU、HBM、网络、光互联、电力、液冷、调度系统组织成更高效的 AI 工厂，谁就拥有基础设施定价权。

从投资视角看，这意味着机会不只在 AI 应用，而在更底层的“卖铲子”环节：

| 主线 | 核心环节 | 观察重点 |
| --- | --- | --- |
| 算力 | GPU、TPU、ASIC、交换芯片、先进封装 | NVIDIA、Google、Broadcom、Marvell、TSMC |
| 存力 | HBM、DRAM、NAND、KV Cache、存储网络 | Micron、SK Hynix、Samsung、长鑫、长存 |
| 互联 | NVLink、InfiniBand、Ethernet、SerDes、DSP | NVIDIA Networking、Broadcom、Marvell |
| 光互联 | CPO、OCS、硅光、光模块、激光器 | Coherent、Lumentum、中际旭创、新易盛、天孚通信 |
| 国产替代 | 光芯片、光器件、设备材料、封装测试 | 光迅科技、源杰科技、华工科技、剑桥科技 |

## 01 · 从 AI 到 Token 工厂

分享里有一个很有穿透力的表达：

> AI = Token = 生产力。

这个理解很适合用来观察 2026 年之后的 AI 基础设施投资。

早期市场更关注模型能力：谁的模型更聪明，谁的上下文更长，谁的多模态更强。但当模型能力逐步扩散后，真正决定商业化效率的是 Token 的生产成本。

Token 成本由几个底层变量共同决定：

- 单卡或单芯片算力。
- 芯片之间的互联效率。
- HBM 和存储系统能否跟上推理负载。
- 数据中心网络是否支持更大规模集群。
- 电力、散热、液冷和运维效率。
- 软件调度是否能把整座集群用满。

因此，AI 数据中心不是普通 IDC，而是“Token 工厂”。它生产的不是网页访问能力，而是推理、生成、智能体执行和多模态服务。

这组数据最值得注意的不是“数据中心很强”，而是网络收入增速显著高于计算收入。它对应分享中的判断：

> 高速互联是最快增长点；未来不是只有算力，而是算力 + 互联为中心。

NVIDIA 在 GTC 2026 也继续把 AI 叙事从“GPU”升级为“AI Factory”。Vera Rubin DSX AI Factory reference design 强调的是 token per watt、整机柜、网络、存储、电力、冷却和运维的整体设计。

Rubin 平台也不是单颗 GPU 的概念，而是 CPU、GPU、NVLink、ConnectX、BlueField、Spectrum-X 共同组成的 rack/pod 级系统。

这说明 NVIDIA 的战略已经很明确：

- 继续控制 GPU 计算核心。
- 用 NVLink、InfiniBand、Ethernet、Spectrum-X 控制集群互联。
- 把 AI 数据中心定义成可复制的工厂架构。
- 让客户买的不只是芯片，而是一套生产 Token 的基础设施。

### 算力：仍然是底座

算力主线包括：

- GPU：NVIDIA 仍是核心。
- TPU：Google 自研路线，围绕 Cloud 和 Gemini 生态展开。
- ASIC：云厂商和大客户会继续推定制芯片。
- 交换芯片：AI 网络扩张带动 Broadcom、Marvell。
- 先进封装：CoWoS、HBM 封装、chiplet、液冷机柜。

### 存力：长上下文和推理带来的新约束

训练阶段需要 HBM，推理阶段同样需要内存和存储。

随着长上下文、智能体、多模态和 KV Cache 放大，存储系统的重要性会上升。

关注方向包括：

- HBM。
- DRAM。
- NAND。
- 高速缓存。
- 分布式存储。
- 数据中心存储网络。

国产替代里，长鑫、长存所在的 DRAM/NAND 方向值得长期跟踪。

### 互联：边际变化最大

互联的核心问题是：大量 GPU/TPU 怎么像一台机器一样协同工作。

如果互联不够快，单卡再强也会被等待、通信、同步拖慢。

所以未来的中心词会从“买 GPU”变成：

- 建集群。
- 建网络。
- 建 AI 工厂。
- 降低 token per watt。
- 降低 token per dollar。

## 05 · 光互联为什么重要

电互联在距离、功耗、带宽密度上会遇到瓶颈。

光互联的价值在于：

- 带宽更高。
- 远距离损耗更低。
- 更适合跨机柜、跨集群通信。
- 在大规模 AI 网络中有更好的能效潜力。

分享中重点提到：

- CPO：Co-Packaged Optics，共封装光学。
- OCS：Optical Circuit Switch，光电路交换/光交换机。
- 硅光：Silicon Photonics。
- 光子互联。
- 光电产业的光学、微电子、机械协同。

### CPO：从板边模块走向封装附近

传统光模块位于板边，电信号需要走较长路径。CPO 的思路是把光引擎靠近交换芯片或计算芯片，缩短电连接距离，降低功耗并提升带宽密度。

短期看，800G/1.6T 可插拔光模块仍然是业绩主线。CPO 不会一夜替代传统模块。

中期看，高端交换机和超大规模 AI 集群会成为 CPO 的重要落地场景。

### OCS：可重构网络的关键

OCS 的意义不只是“用光交换”，而是让数据中心网络更容易动态重构。

在 AI 训练和推理中，不同任务、不同模型、不同集群规模对网络拓扑要求不同。OCS 配合软件定义网络，可以更灵活地重组网络资源。

这就是 Google 长期投入 OCS 的原因。

### 硅光：光电集成的量产路径

硅光不是单一产品，而是一套产业链。

它涉及：

- 激光器。
- 调制器。
- 探测器。
- 光波导。
- 光纤耦合。
- 光引擎。
- 封装测试。
- 光电协同设计。

因此，硅光机会不是只看一家“纯硅光公司”，而要看整条光电互联生态。

## 08 · 量子科技与卫星互联网：下一阶段战略方向

分享中除了 AI 基础设施，还提到两个中长期方向：

- 量子科技。
- 卫星互联网。

这两个方向更偏“十五五”战略科技方向。它们和 AI 基础设施不同，商业化节奏更不确定，但政策、国防、通信、算力网络、安全体系中的战略意义更强。

如果用组合思路理解：

- AI 基础设施：当下主线，收入和订单更容易验证。
- 量子科技：长期战略弹性。
- 卫星互联网：空间通信和全球网络基础设施弹性。

## 09 · 投资框架：只投卖铲子

分享里最值得保留的方法论是：

> 只投资卖铲子。

这句话在 AI 周期里非常实用。

应用层会百花齐放，但竞争格局变化快，产品形态也会不断重构。基础设施层虽然估值也会波动，但需求更容易从巨头 CapEx、供应链订单、产能扩张中验证。

我会把优先级理解为：

1. 算力底座：GPU、TPU、ASIC、先进封装。
2. 存储底座：HBM、DRAM、NAND、存储网络。
3. 高速互联：交换芯片、SerDes、DSP、网络设备。
4. 光互联：800G/1.6T、CPO、OCS、硅光、光源。
5. 国产替代：存储、光芯片、光器件、设备材料。
6. 战略弹性：量子科技、卫星互联网。

更务实一点：

> 不要只买“CPO 概念”，优先看已经在 800G/1.6T 赚钱，同时又在光引擎、硅光、CPO、OCS 卡位的公司。

## 10 · 需要持续跟踪的指标

| 指标 | 为什么重要 |
| --- | --- |
| 云巨头 CapEx 是否继续上修 | 决定 AI 基础设施总需求 |
| NVIDIA Networking 增速 | 验证互联是否继续高于计算增长 |
| Broadcom/Marvell AI 网络收入 | 验证交换芯片、DSP、ASIC 景气度 |
| 800G/1.6T 光模块出货 | 验证当下业绩主线 |
| CPO/OCS 商用节奏 | 验证下一阶段估值弹性 |
| HBM 供需和价格 | 验证存力瓶颈 |
| 国内光芯片国产化率 | 验证国产替代空间 |
| 出口管制和供应链政策 | 影响中美产业链分化 |

## 风险提示

这条产业链机会很大，但波动也会很大。

主要风险包括：

- AI CapEx 周期低于预期。
- CPO/OCS 商用节奏慢于市场预期。
- 可插拔光模块生命周期比预期更长。
- 光模块价格竞争压缩利润。
- 客户集中度高。
- 出口管制和供应链限制。
- 估值提前反映未来多年增长。

因此，更稳妥的方式不是押单一概念，而是持续跟踪真实订单、收入、毛利率、CapEx 和技术路线兑现。
