AI 服务 & 费用

🤖 MiniMax-M3 VLM (Understand 阶段)

每个 clip 抽帧后调用一次，识别菜品、动作、视觉风格、钩子适配度
单次费用：¥0.005 / clip

🧪 MiniMax-M3 LLM (Copy + Queue Worker)

Copy 阶段：每个 combo × 模板生成字幕文案（有 cache 则跳过）
beatmix：槽位候选编排、ASR kind 标注
inspiration：爆款规律聚合、逐套餐拍摄建议
Queue Worker：解释复审 prompt → 视频参数 delta
单次费用：¥0.001 / call

🎙 DashScope ASR (beatmix Voicemap)

离线生成口播 BGM 的词级时间戳，再由 LLM 标注 intro / dish / filler 等槽位。
产物：config/bgm_voicemap/{bgm_id}.json

📊 7维差异化引擎

本地无 API 费用。对每批次候选做 diff 打分，确保每次出片与历史不同
D1 首帧 clip
D2 片段序列
D3 BGM
D4 转场类型
D5 语义标签
